# 🤍 Carta para Nicol con D

Una carta de amor interactiva hecha con Streamlit.

## Cómo correr localmente

```bash
pip install streamlit
streamlit run nicol_carta.py
```

## Cómo desplegar en Streamlit Cloud

1. Sube este repo a GitHub (público)
2. Ve a [share.streamlit.io](https://share.streamlit.io)
3. Conecta tu GitHub y selecciona este repo
4. Archivo principal: `nicol_carta.py`
5. Deploy ✨
